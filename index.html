ScanX — AI-Based Vulnerability Assessment System

An autonomous AI-assisted vulnerability assessment system designed to identify potential security weaknesses, validate threats through dual-AI consensus, and help users understand and prioritize findings.

Verified Key Features

  • Multi-module vulnerability scanning — 8 active & passive checking modules (Headers, SSL/TLS, CORS, XSS, SQLi, sensitive endpoints, secrets, robots.txt)
  • Dual-AI threat verification — Role separation between Agent 1 (Threat Modeler) and Agent 2 (Skeptical Auditor) to eliminate false positives
  • Vulnerability severity classification & security scoring — Explainable 0–100% confidence score mathematically weighted across execution, response deltas, and consensus
  • Scan history and audit records — Persistent SQLite repository tracking scans, findings, and JSON telemetry
  • Detailed findings and evidence — Real-time canary reflection analysis, status deltas, and evidence logs
  • PDF security report generation — Automated vector PDF and printable audit reports for security stakeholders
